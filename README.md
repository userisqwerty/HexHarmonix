# 🎹 HexHarmonix

I built a cozy, retro analog synthesizer dashboard from scratch!

### How to play:
1. Click the red **POWER MAIN ENGINE** button to turn it on.
2. Type **A, S, D, F, G, H, J** on your laptop keyboard (or click the visual buttons) to play a musical scale.
3. Move the sliders to warp the pitch, and change the dropdown menu to select different synth waveforms!

### How it works:
* **HTML/CSS:** Custom-built layout grids, smooth floating shadows, and interactive click animations that match the Crescent theme.
* **JavaScript:** Uses the browser's native **Web Audio API** to synthesize math-driven sound frequencies completely from scratch instead of playing pre-recorded audio tracks!
